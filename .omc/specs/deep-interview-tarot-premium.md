## Goal

"돈 내고 볼 만하다"는 느낌 = 다음 4가지가 동시에 충족될 때:
1. **내 상황을 꿰뚫는 느낌** — 내가 말하지 않은 것까지 맞히는 인사이트
2. **위로와 감정 해소** — 불안이 가라앉는 카타르시스
3. **실질적인 행동 지침** — 오늘 바로 쓸 수 있는 구체적 조언
4. **신비롭고 몰입되는 경험** — 의식(ritual)처럼 느껴지는 흐름

그 위에 **"진짜 행운을 얻은 것 같은 느낌"** — 카드가 나를 위해 나타난 것 같고, 오늘 하루 들고 다닐 무언가를 받은 기분.

## 핵심 변경사항 (브라운필드)

### 1. 플로우 재설계

**AS-IS:**
```
카테고리 선택 → 카드 섞기 → 카드 선택 → 결과
```

**TO-BE:**
```
카테고리 선택 → 인테이크 질문(3개) → 카드 섞기 → 카드 선택 → 결과(풍성)
```

### 2. 인테이크 질문 — 카테고리별 3개 (새 컴포넌트)

카드 뽑기 전, 버튼/단답 조합으로 빠르게 진행. 입력 내용은 AI 프롬프트에 전달됨.

**오늘의 운세**
1. 지금 가장 마음에 걸리는 게 하나만 말해주세요. (짧은 텍스트)
2. 지금 나의 에너지는? (버튼: 지쳐있어 / 불안해 / 뭔가 기대돼 / 그냥 평범해)
3. 오늘 어떤 말을 듣고 싶어요? (버튼: 응원 / 솔직한 조언 / 그냥 내 편 들어줘 / 방향 잡아줘)

**연애운**
1. 지금 상대 생각하면 드는 감정 하나. (짧은 텍스트)
2. 지금 이 관계에서 내가 원하는 건? (버튼: 더 가까워지고 싶어 / 명확히 하고 싶어 / 그냥 안심하고 싶어 / 잊고 싶어)
3. 상대에게 지금 가장 바라는 건? (버튼: 관심 / 솔직함 / 행동 / 그냥 곁에 있어줬으면)

**직업운**
1. 요즘 일하면서 가장 힘든 게 뭐예요? (짧은 텍스트)
2. 지금 내 상황은? (버튼: 새로운 시작 앞 / 막혀있어 / 선택 기로 / 지쳐서 쉬고 싶어)
3. 오늘 일에서 원하는 건? (버튼: 돌파구 / 버텨낼 힘 / 방향 확신 / 작은 성취)

**금전운**
1. 요즘 돈 얘기 나오면 드는 감정. (짧은 텍스트)
2. 지금 금전 상황은? (버튼: 여유있어 / 빠듯해 / 큰 결정 앞 / 불확실해)
3. 오늘 바라는 건? (버튼: 안심 / 기회 신호 / 절약 팁 / 그냥 잘 될 거라는 말)

### 3. 결과 화면 — 4섹션으로 확장

**AS-IS:** 헤드라인 + 짧은 운세 (150-200자)

**TO-BE:**

```
[카드 등장 — 비주얼 씬네스]
파티클 + 빛 효과 + 카드 플립

─────────────────────────
🃏 카드 해석
이 카드는 원래 어떤 에너지인지 2-3문장.
(카드 자체의 의미, 역방향 포함)

─────────────────────────
💬 지금 너에게 하는 말
인테이크 답변을 반영한 개인화 메시지.
직접적이고 솔직한 응원자 톤.
3-4문장. "너", "네가" 2인칭 직접 호칭.

─────────────────────────
✨ 오늘의 키워드 · 색깔
키워드: [단어 1-2개]     색깔: [색이름 + 컬러칩]

─────────────────────────
🌟 오늘의 행운 만트라
복사/공유 가능한 짧은 문장.
오늘 하루 마음속에 품고 다닐 것.
```

### 4. AI 프롬프트 재설계

**입력:** cardId, isReversed, category, intakeAnswers(객체)

**출력 JSON:**
```json
{
  "cardInterpretation": "카드 자체의 에너지와 의미 (2-3문장)",
  "personalMessage": "인테이크 기반 개인화 메시지, 2인칭 직접 (3-4문장)",
  "keyword": "오늘의 키워드 1-2단어",
  "color": { "name": "색이름", "hex": "#RRGGBB" },
  "mantra": "오늘의 행운 만트라 (한 문장, 품고 다닐 수 있는 것)"
}
```

**페르소나:** 직접적이고 솔직한 응원자
- "나는 네 편이야, 근데 솔직하게 말할게"
- 신비로운 리더 X, 모호한 위로 X
- "너 지금 이런 거 아냐?" 식의 꿰뚫는 직접성
- 2인칭 호칭 ("너", "네가", "지금 네 상황")
- 금지: 막연한 긍정, "우주가", "에너지가 흐른다"

### 5. 비주얼 씬네스 — 카드 등장 연출 강화

카드를 뽑는 순간이 의식(ritual)처럼 느껴져야 한다.

- 카드 플립 시 파티클 이펙트 (황금빛 먼지)
- 카드 테두리에서 빛이 번지는 glow 애니메이션
- 배경에 해당 카드 컬러(오늘의 색깔)가 은은하게 스며드는 효과
- 카드가 "선택받아 나타난" 느낌을 주는 타이밍과 속도

## Constraints
- 기존 78장 카드 데이터, 이미지, 기본 플로우 유지
- 인테이크는 3단계로 제한 (이탈 방지)
- 인테이크 총 시간 < 30초 (버튼 위주)
- 결과 텍스트는 AI 없이도 fallback 제공
- 모바일 퍼스트 레이아웃

## Non-Goals
- 멀티 카드 스프레드 (켈틱 크로스 등) — 이번 버전 제외
- 사용자 계정/히스토리 — 이번 버전 제외
- 유료 결제 연동 — 이번 버전 제외
- 음향 효과 — 선택적 (있으면 좋지만 필수 아님)

## Acceptance Criteria
- [ ] 카테고리 선택 후 카테고리별 다른 3개 질문이 나온다
- [ ] 질문 3개 완료 후 카드 섞기로 넘어간다
- [ ] 인테이크 답변이 API 요청에 포함된다
- [ ] 결과 화면에 카드 해석 / 나에게 하는 말 / 키워드+색깔 / 만트라 4섹션이 존재한다
- [ ] "나에게 하는 말"이 인테이크 답변을 반영한다 (언급하거나 맥락을 사용)
- [ ] 오늘의 색깔이 배경에 은은하게 반영된다
- [ ] 만트라를 클립보드에 복사할 수 있다
- [ ] 카드 등장 시 파티클/glow 비주얼 이펙트가 있다
- [ ] 모바일에서 인테이크 질문이 잘 보인다
